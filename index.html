Week 4 Reflection

This week, we learned more about loops and how to use if and else statements in programming. These gave us more possibilities to create different results.

For example, we can use loops to draw many circles, and use conditions to decide when something should move, change or stay still. By combining these ideas with mathematical calculations, we can create more complex patterns and interactions.

We also learned about logical operators such as AND and OR, which allow us to create more conditions in our code.

I feel that creative coding is becoming more and more like mathematics. Sometimes it is quite complicated for me, but I can also see how these tools give us more creative possibilities. I am still learning and trying to understand them better.
